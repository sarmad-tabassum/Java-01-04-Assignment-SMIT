### 📦 How to Run Locally

You can execute, compile, and test these Java files instantly on your system by following these simple steps:

1. **Prerequisite:** Make sure you have the Java Development Kit (JDK) installed on your system.

2. **Clone the Repository:**
```bash
   git clone [https://github.com/sarmad-tabassum/java-01-04-assignment-smit.git](https://github.com/sarmad-tabassum/java-01-04-assignment-smit.git)
Navigate to the Project Folder:

Bash
   cd java-01-04-assignment-smit
Compile the Java File:

Bash
   javac Main.java
(Note: Replace Main.java with the specific assignment file name if needed)

Execute the Compiled Bytecode:

Bash
   java Main
